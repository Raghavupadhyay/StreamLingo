# StreamLingo

> "I don't need instant translation. I need correct understanding."

StreamLingo is an accuracy-first conversation translator for interviews and other high-stakes conversations.  
It intentionally uses controlled latency (default 5-10 seconds) so translation can use context instead of guessing too early.

---

## ✨ Features

- Local audio capture from selected input device (mic or virtual device like BlackHole)
- Streaming chunker with adaptive VAD gating
- `faster-whisper` STT stage (with optional mock fallback if dependency is missing)
- Context window buffer for translation continuity
- LLM translation adapter (OpenAI provider or mock passthrough)
- Ordered delay queue for stable controlled-latency subtitle emission
- Live subtitle UI over WebSocket
- Structured logging to JSONL and SRT export for review
- Replay endpoint to rerun translation on saved transcripts

### 🆕 Smart VAD (Voice Activity Detection)

StreamLingo now includes an advanced multi-stage VAD pipeline that improves speech segmentation and translation quality.

#### 🔹 Key Improvements
- Replaces fixed 2-second chunking with adaptive segmentation
- Emits audio at natural speech boundaries
- Filters silence and background noise
- Detects speaker changes in two-person conversations
