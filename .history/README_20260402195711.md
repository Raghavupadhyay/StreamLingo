Quick Start
1) Install dependencies (uv)
uv sync
2) (macOS) route meeting audio if needed
Install a virtual audio device such as BlackHole.
Route Zoom/Meet output to that device.
Set SL_INPUT_DEVICE_INDEX to the matching input index from /devices.
3) Configure environment

Create a .env or export vars in shell:

export SL_SOURCE_LANGUAGE=ja
export SL_TARGET_LANGUAGE=en
export SL_TARGET_DELAY_SECONDS=7.0
export SL_CHUNK_SECONDS=2.0
export SL_CONTEXT_MAX_SENTENCES=6
export SL_TRANSLATION_PROVIDER=mock
# export SL_TRANSLATION_PROVIDER=openai
# export OPENAI_API_KEY=...
4) Run backend
uv run --env-file .env -- python -m uvicorn app.main:app --reload --app-dir backend

Then open http://127.0.0.1:8000

API Endpoints
GET /health: status + provider mode
GET /devices: list available audio input devices
POST /pipeline/start: start capture/transcribe/translate stream
POST /pipeline/stop: stop the stream
POST /pipeline/replay: replay translation from saved transcript JSONL
WS /ws/subtitles: live subtitle events
Accuracy-First Workflow
Run live session and collect logs under runs/<timestamp>/.
Review:
events.jsonl for stage-by-stage trace
subtitles.srt for translation quality and timing
Tune:
SL_TARGET_DELAY_SECONDS
SL_CONTEXT_MAX_SENTENCES
translation prompt/model
Use /pipeline/replay on saved transcripts to iterate without recapturing audio.

Current Limitations
No diarization (single mixed speaker stream)
Speaker change detection is optimized for two-speaker conversations
Translation quality depends on selected provider/model
TTS speech output is not part of MVP yet
Roadmap
Improve multi-speaker diarization support
Add Redis-backed context/session state
Add bidirectional translation modes
Add optional TTS after subtitle accuracy is stable
Add objective evaluation scripts (WER + human rubric tooling)
